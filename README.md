# SoundMatch 0.5

好きな曲の指定区間に音響的に似た公開音源を探すWindowsアプリ。検索先はWikimedia Commonsであり、世界中の商用楽曲すべては対象ではありません。

## Setup

`SoundMatch_AI_WindowsBuild_v05.zip` を展開し、ソース一式をリポジトリのルートへアップロードしてください（READMEは上書きして構いません）。

GitHub Actionsの `Build SoundMatch AI Windows` を実行し、成功後は `SoundMatchAI-Windows-Portable` を取得してください。初回検索時はCLAPモデルのダウンロードが必要です。
